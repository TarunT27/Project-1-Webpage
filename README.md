# Project 1 - Webpage

A personal website by Tarun Tata for Project 1.

- `index.html`: home page and personal interests
- `myUniversity.html`: Rutgers University–Newark and my studies
- `resume.html`: resume and certificates
- `styles.css`: shared responsive and print styles

Published website: https://TarunT27.github.io/Project-1-Webpage/

Open `index.html` in any browser to view locally. No installation or build step is needed.

GitHub Pages publishes from the root of the `main` branch. Push changes to `main` to update the website.
